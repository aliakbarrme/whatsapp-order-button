Add an Order on WhatsApp button to WooCommerce products with product, quantity, variation and price pre-filled.

== Description ==

In Bangladesh, India and many other markets, customers prefer to order and ask questions on WhatsApp. This turns every product page into a direct sales chat.

* Button on single product pages, next to Add to cart
* Optional button on shop / category pages
* Includes the selected quantity and variation (size, color…) and the variation price
* Fully editable message template: {product} {variation} {qty} {price} {sku} {url} {site}
* WhatsApp-only store mode hides Add to cart
* Floating WhatsApp chat button on every page
* Custom button text and color; no extra CSS/JS files, no tracking

== Installation ==

1. Upload the plugin ZIP via Plugins > Add New > Upload Plugin.
2. Activate it.
3. Open Settings → WhatsApp Order.
